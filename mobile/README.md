# Court Scope — iOS/Android (Expo WebView)

React Native / Expo app that wraps the Court Scope web app in a native shell for TestFlight and Play Store distribution.

## First-time setup

```bash
cd mobile
npm install
npx eas-cli@latest login        # sign in with your Expo account
npx eas-cli@latest build:configure  # only needed once; links to the EAS project
```

## Build & submit to TestFlight

```bash
npx eas-cli@latest build --platform ios --auto-submit
```

This produces a production build, increments the build number automatically, and uploads directly to App Store Connect / TestFlight.

## Update an existing TestFlight build (expired or new version)

Same command as above — `autoIncrement: true` in `eas.json` bumps the build number each time:

```bash
cd mobile
npm install
npx eas-cli@latest build --platform ios --auto-submit
```

## Project files

| File | Purpose |
|------|---------|
| `App.js` | WebView shell with offline screen, Android back handler, iOS safe-area handling |
| `app.json` | Expo config — bundle ID, icons, splash, orientations |
| `eas.json` | EAS Build config — production profile, remote version, auto-increment |
| `assets/` | App icons generated by `../scratchpad/gen-icons.js` |

## Bundle identifier

`com.ashlancunningham.stats`

## Regenerating icons

```bash
cd <repo-root>
node scratchpad/gen-icons.js
```

Requires `playwright-core` and Chromium (`npx playwright install chromium`).
